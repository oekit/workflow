```bash
go get github.com/oekit/workflow@v0.2.5
```

## 这个仓库做什么

`workflow` 是**组合式流程编排框架**：串行/并行/异步/条件分支四种模式任意嵌套，
Hook AOP 自动向子流程递归传播，context 取消自动传递，panic 全量 recover。

## 四种流

| 流 | 语义 |
|---|---|
| `PipeFlow` | 串行管道：步骤依次执行，任一失败即中止 |
| `ParallelFlow` | 并行：并发执行（可限并发数），聚合错误 |
| `AsyncFlow` | 异步：提交后收集结果，错误经 resultFn 上抛 |
| `SwitchFlow` | 条件分支：按判定选择子流程 |

## 快速使用

```go
import "github.com/oekit/workflow/workflow"

p := workflow.NewPipe()
p.Add(step1, step2, workflow.NewParallel(4))
err := p.Run(ctx)
```

## Hook AOP

`HookManager` 注册 Before/After/成功/失败钩子，自动递归传播到所有子流程——
审计日志、链路打点、熔断注入都不用改业务步骤。

## 边界

- 步骤是任意 `Runnable`（`Run(ctx) error`）；定时触发用 [timertask](https://github.com/oekit/timertask)
